# Fotos del álbum

Pon aquí sus fotos (JPG o WebP, idealmente cuadradas o casi cuadradas, ~1200 px de lado).

Luego abre `src/data/mensajes.ts`, busca `recuerditos.fotos` y escribe la ruta de cada una:

```ts
{ foto: '/assets/fotos/01.jpg', titulo: 'Este día', fecha: '14 de febrero', texto: '...' },
```

Puedes agregar o quitar fotos de la lista; el álbum se acomoda solo.
